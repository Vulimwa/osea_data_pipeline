# OSEAS dataset catalog and status

The single machine-readable registry is [`../config/data_catalog.json`](../config/data_catalog.json); both the Python catalog audit and Node API read it. Registry presence means “identified for integration,” not “retrieved.” A dataset is considered retrieved only when the relevant adapter succeeds and a run/version or successful retrieval timestamp is persisted.

## Acceptance and status rules

`npm run oseas:catalog:audit` checks a small Nairobi bounding box and date windows for selected Earth Engine collections. The 2026-10-14 read-only smoke audit retrieved CHIRPS (30 images), ERA5-Land (30), ERA5 daily (30, April 2019), Sentinel-1 (4), Sentinel-2 SR/L1C (6 each), Landsat 8 L2 (2), DEM, JRC surface water and MODIS burned area (12). It reports availability and bands; it does not download full rasters or write database records. Other non-Earth-Engine sources were not tested by this smoke run.

The bounded flood processor additionally requires non-empty Sentinel-1 event and baseline collections, at least 70% union-footprint coverage in each window, same orbit pass, a DEM and JRC water image, and successful CHIRPS retrieval or an explicit zero-count warning. Raster products remain in Earth Engine; only bounded vector candidates and summary features are stored in PostGIS.

## Newly configured and verified map layers

On 2026-10-14 the three Kenya GWA rasters were downloaded and inspected. They each contain 4,287 x 3,829 cells at 0.0025 degree spacing in WGS 84 geographic coordinates. Valid sample coverage in the Kenya bounding envelope was 70.3%. The sample ranges were 0.0441–17.2 m/s wind speed, 0.0000021–8,070 W/m2 power density, and 0.728–1.17 kg/m3 air density. These are inspection-sample ranges, not national summary statistics. The GeoTIFF bands do not embed unit metadata; the manifest records the product unit convention explicitly. Negative values outside valid physical resource ranges are masked in map copies and remain documented in the manifest.

The supplied Global Wind Atlas country GeoJSON URL returned HTTP 400 at audit time. The official GIS page describes the country TIF/GeoJSON downloads and says the API should not be used for bulk downloads: [Global Wind Atlas GIS files & API access](https://globalwindatlas.info/en/download/gis-files). OSEAS uses the already ingested administrative boundaries for reporting geography. Do not interpret wind-resource values as extreme-wind hazards.

`npm run oseas:wind:sync` is the bounded, repeatable cache adapter. It validates file type, raster readability, coordinate reference, dimensions, bounds and sampled valid pixels, and writes checksums and metadata to the ignored local data directory. After cache, `/api/v1/oseas/layers/wind_resource` lists map URLs and `/geotiff` routes stream each raster. Production deployments must provide durable shared storage for the raster directory if API instances are not colocated with the cache.

Population exposure has a source-specific WorldPop adapter and 374 persisted event/administrative rows. NASA POWER 2024 heat exposure is persisted with 101,987 asset rows and 1,261 county/ward summaries. Nighttime lights have a first-class quality-aware adapter and map layer; the token alias is configured, but manifest-selected months are still needed before radiance acquisition. Service dependency distinguishes verified, candidate and unknown links; there are no verified feeder/service relationships yet. CHIRPS/ERA5 standalone rainfall anomalies, future projections, Landsat LST, drought indicators, burned-area exposure, Kenya-specific model validation and outage-based reliability assessment remain outstanding.
